TELC B2 Schreiben · 老师给的投诉信 Redemittel

① Betreff + Anrede

Betreff: Beschwerde über ...
主题：投诉关于……
Sehr geehrte Damen und Herren,

② Einleitung · Anlass der Beschwerde

Ich wende mich an Sie, weil/da/denn ...
我联系您是因为……
Bedauerlicherweise / Mit Bedauern / Leider muss ich mich über ... beschweren.
很遗憾，我不得不投诉……
Mit diesem Schreiben möchte ich Sie über die Unannehmlichkeiten informieren, ...
通过这封信，我想向您说明所遇到的不便……
Ich habe bei Ihnen am ... erworben / gebucht / online über Ihre Webseite bestellt, jedoch / allerdings / aber ...
我于……在贵处购买/预订/通过网站订购了……，然而……
Nachdem ich ..., ...
在我……之后，……

③ Beschreibung des Problems

Zu meinem Bedauern musste ich feststellen, dass ...
遗憾的是，我不得不发现……
Entgegen Ihrer Beschreibung / Werbung war ...
与您的描述/广告相反，……
Obwohl in der Anzeige stand, dass ...
尽管广告中写着……
Zwar stand in der Anzeige, dass ..., aber ...
广告中虽然写着……，但是……
Das Produkt / die Dienstleistung entsprach nicht meinen Erwartungen, da/weil/denn ...
产品/服务没有达到我的预期，因为……
Besonders enttäuschend war, dass ...
尤其令人失望的是……

④ Ausdruck von Enttäuschung / Kritik

Ich bin sehr enttäuscht / frustriert / verärgert über ...
我对……非常失望/沮丧/生气。
So etwas hatte ich nicht erwartet.
我没想到会发生这样的事情。
Das finde ich sehr ärgerlich / unzumutbar / unprofessionell / nicht akzeptabel.
我认为这非常令人恼火/无法接受/不专业/不可接受。
Unter diesen Umständen sehe ich mich gezwungen, ...
在这种情况下，我不得不……

⑤ Forderungen / Wünsche

Ich erwarte eine Rückerstattung / einen Umtausch / eine Nachbesserung.
我要求退款/换货/改进或修复。
Eine Rückerstattung / einen Umtausch / eine Nachbesserung halte ich in diesem Falle / aufgrund der oben genannten Gründe für angemessen.
基于上述理由，我认为退款/换货/修复在这种情况下是合理的。
Bitte senden Sie mir ...
请给我寄送……
Ich bitte Sie um eine schriftliche Stellungnahme bis zum ...
请您在……之前给我一份书面回复/说明。
Ich hoffe, dass Sie mir entgegenkommen und ...
希望您能够体谅并……
Sollte ich keine Reaktion bis ... erhalten, sehe ich mich veranlasst, die Verbraucherzentrale zu informieren / einen kritischen Kommentar auf Ihrer Homepage zu verfassen bzw. zu hinterlassen.
如果截至……我仍未收到回复，我将不得不联系消费者中心/在您的主页留下批评性评论。

⑥ Schlussformeln

Ich danke Ihnen im Voraus für Ihre Mühe.
提前感谢您的努力。
Für eine zeitnahe Rückmeldung wäre ich Ihnen sehr dankbar.
如果您能尽快回复，我将非常感谢。
Mit freundlichen Grüßen
