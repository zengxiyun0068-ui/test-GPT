🔥 Grammatik · 德语四格 & 形容词变位

Akkusativ · Dativ · Genitiv · ein/eine · 形容词变位

📚 先搞清楚：他们是谁？

Nominativ

谁/什么？ → 主语，做动作的人/东西。

Der Mann kauft einen Apfel.

谁买？→ Der Mann

Akkusativ

谁/什么？ → 直接宾语，动作直接作用于谁/什么。

Der Mann kauft einen Apfel.

买什么？→ einen Apfel

Dativ

给谁？对谁？ → 间接宾语，也常由固定动词/介词要求。

Ich gebe dem Mann einen Apfel.

给谁？→ dem Mann

Genitiv

谁的？ → 所属关系，相当于“……的”。

Das ist das Auto des Mannes.

谁的车？→ des Mannes

🔥 一句话： Nominativ = 谁做事 → Akkusativ = 做什么/谁 → Dativ = 给谁/对谁 → Genitiv = 谁的。

2️⃣ 不定冠词：ein / eine

阳性阴性中性
Neineineein
Aeineneineein
Deinemeinereinem
Geineseinereines
🔥 最容易考的变化： 阳性 Akk：der → den，ein → einen。Dativ：der → dem、die → der、das → dem、复数 die → den。Genitiv：der/das → des，die/复数 → der。

3️⃣ Dativ / Akkusativ：怎么判断？

Ich sehe den Mann.

sehen + Akk → 我看到谁？den Mann。

Ich helfe dem Mann.

helfen + Dat → 我帮助谁？dem Mann。

Ich gebe dem Mann den Schlüssel.

给谁？dem Mann = Dativ；给什么？den Schlüssel = Akkusativ。

常见 Akkusativ 动词

sehen, kaufen, haben, brauchen, besuchen, fragen, lieben, hören, lesen

常见 Dativ 动词

helfen, danken, gefallen, gehören, folgen, vertrauen, antworten, fehlen, schmecken

常见 Genitiv 介词（B2 很有用）

wegen, trotz, während, aufgrund, außerhalb, innerhalb, statt/anstatt

wegen des Wetters · trotz des Problems · aufgrund der Situation

4️⃣ eine + 形容词：完整规则

重点：冠词先变，形容词再看词尾。 不定冠词没有把所有格信息全部显示出来，所以部分位置由形容词“补出来”。

阳性阴性中性
Nein guter Manneine gute Frauein gutes Kind
Aeinen guten Manneine gute Frauein gutes Kind
Deinem guten Manneiner guten Fraueinem guten Kind
Geines guten Manneseiner guten Fraueines guten Kindes
🔥 背这个就够考试用：
N 阳：ein guter · N 阴：eine gute · N 中：ein gutes
A 阳：einen guten · A 阴：eine gute · A 中：ein gutes
D：三个性别基本都是 -en · G：三个性别基本都是 -en

5️⃣ 定冠词 + 形容词

阳性阴性中性复数
Nder gutedie gutedas gutedie guten
Aden gutendie gutedas gutedie guten
Ddem gutender gutendem gutenden guten
Gdes gutender gutendes gutender guten
🔥 口诀：有 der/die/das 这类定冠词时，形容词绝大多数是 -en；只有 Nominativ 单数和 Akkusativ 阴/中性是 -e。

6️⃣ 没有冠词：强变化

阳性阴性中性复数
Nguter Manngute Fraugutes Kindgute Kinder
Aguten Manngute Fraugutes Kindgute Kinder
Dgutem Mannguter Fraugutem Kindguten Kindern
Gguten Mannesguter Frauguten Kindesguter Kinder

🧠 考试做题顺序

  1. 先找动词/介词：要求 Akk、Dat 还是 Gen？
  2. 判断角色：主语 N？直接宾语 A？间接宾语 D？所属 G？
  3. 判断性别和单复数。
  4. 先变冠词：der → den/dem/des；ein → einen/einem/eines。
  5. 最后看形容词词尾。
最重要：不要一看到形容词就猜 -e/-en。先判断 N/A/D/G → 性别 → 冠词，词尾就出来了。
