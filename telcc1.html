🧠 Teil 1 做题方法

不要背全文，背“这个空需要什么功能”。
  1. 先看空格前后，不要一开始逐词翻译全文。
  2. 抓指代：diese / sie / solche / dazu / zu diesem Schluss。
  3. 抓逻辑词：aber / doch / jedoch / dennoch / deshalb / in der Folge。
  4. 看重复词：如 Faktoren → solche Faktoren。
  5. 判断功能：解释、结果、转折、例子、总结、解决办法。
  6. 最后用语法和搭配确认；主题相关 ≠ 逻辑正确。
两篇口诀：
① 标准→结果→人数→反驳→结论→因素
② 计算力→人类优势→伦理机构→能耗→培训→创新
